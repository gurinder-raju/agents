One request, AWS and Google side by side

Managed service Open source or your code Sandbox network traffic
  • The harness is the brain. It runs in the runtime and calls the model. Code and browsing run in a separate sandbox, the hands.
  • On Google, the sandbox holds no credentials. Its traffic leaves through Agent Gateway, which checks identity and adds the credential on the way out.
  • Your agent and harness code moves between clouds. The front door, control plane, runtime and gateway are each cloud's own.

The AWS version, up close

The request runs straight down the middle. The blocks on either side are used alongside it: set up once at deploy time, asked for credentials, or optional.

Google's agent compute layer, and the AWS parallel

Agent Compute Engine (announced 22 Oct 2026) is the managed version of what Google already runs Gemini's agents on. The self-hosted version is three open-source layers on your own Kubernetes cluster: Agent Executor (AX) orchestrates agent tasks, Agent Substrate places them on machines, and GKE Agent Sandbox isolates each one.
